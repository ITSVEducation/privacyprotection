# 個人情報マスキング（PrivacyProtection）

**ChatGPT などの AI に文章を貼り付ける前に、名前・電話番号・住所などの個人情報を自動で「隠す」ための Windows 用アプリです。**

<p align="center">
  <img src="docs/images/main-window.png" alt="アプリのメイン画面" width="520">
</p>

AI サービスはとても便利ですが、社外秘の資料やお客様の個人情報をそのまま貼り付けてしまうと、その情報が外部に送られてしまいます。このアプリを使うと、

1. 文章の中の個人情報を **記号や仮の名前に置き換え（マスク）** てから AI に渡し、
2. AI から返ってきた文章を **元の情報に戻す（復元）**

という使い方ができます。**すべてお使いのパソコンの中だけで動き、インターネットには一切送信しません。**

> ⚠️ 自動検出は完全ではありません。重要なデータは、後述の「確認画面（プレビュー）」で必ず目視チェックしてください。

## こんな方におすすめ

- ChatGPT や Copilot などの AI に、社内文書や顧客情報を安全に相談したい方
- Excel・Word・PowerPoint の中の個人情報をまとめて隠したい方
- 難しい設定なしで、ダウンロードしてすぐ使いたい方

**専門知識は不要です。** パソコンにファイルをダウンロードして、ダブルクリックで起動するだけで使えます。

## 動作環境

- **Windows 10 または Windows 11（64ビット）**
- インストール作業や管理者権限は不要です（フォルダを置くだけ）
- インターネット接続は不要です

## ① ダウンロードとインストール

> 💡 「インストール」といっても、**専用のインストーラーは使いません。** ダウンロードしたフォルダを好きな場所に置くだけです。

### 手順

1. このページの上部（または右側）にある **「Releases（リリース）」** をクリックします。
   （直接開く場合はこちら → https://github.com/ITSVEducation/privacyprotection/releases ）

2. 最新版の中にある **`PrivacyProtection.zip`** をクリックしてダウンロードします。

3. ダウンロードした `PrivacyProtection.zip` を右クリックし、**「すべて展開」** を選びます。
   （ZIP は「圧縮された箱」です。展開＝箱を開けて中身を取り出す作業です）

4. 展開してできた **`PrivacyProtection` フォルダ** を、デスクトップなど分かりやすい場所に移動します。

5. フォルダの中の **`PrivacyProtection.exe`** をダブルクリックすると、アプリが起動します。

> 💡 よく使う場合は、`PrivacyProtection.exe` を右クリック →「スタートメニューにピン留めする」または「ショートカットの作成」をしておくと便利です。

### ⚠️ 「Windows によって PC が保護されました」と表示されたら

初めて起動するとき、青い警告画面が出ることがあります（Microsoft に登録されていない個人開発アプリで一般的に出るものです）。中身は安全なので、次の操作で起動できます。

1. **「詳細情報」** をクリック
2. 下に出てくる **「実行」** ボタンをクリック

## ② いちばん簡単な使い方（コピー＆ペースト）

**まずはこの方法を試してください。** ファイルを用意する必要がなく、コピーした文章をその場でマスクできます。

### マスクする（AI に渡す前）

1. 隠したい文章を、いつも通りマウスで選択して **コピー**（Ctrl+C）します。
2. アプリの画面上部で **「マスク」** が選ばれていることを確認します。
3. **「クリップボードをマスクしてコピー」** ボタンを押します。
4. [確認画面（プレビュー）](#確認画面プレビューで目視チェック)が開くので、隠す箇所を確認して **「この内容でマスク実行」** を押します。
   （「確認なしで即変換」にチェックを入れている場合は開きません。ここで Cancel を押すと、コピーした内容はそのまま残ります）
5. これで、クリップボードの中身が「マスク済みの文章」に入れ替わりました。
   AI の入力欄に、そのまま **貼り付け**（Ctrl+V）してください。

例：

|          | 文章                                                         |
| -------- | ------------------------------------------------------------ |
| マスク前 | 契約担当の**山田太郎**です。連絡先は **03-1234-5678** です。 |
| マスク後 | 契約担当の**【人名_1】**です。連絡先は **【電話_1】** です。 |

同じ名前は必ず同じ記号（`【人名_1】`）になるので、AI は「誰の話か」を区別したまま回答できます。

> 💡 このとき、元に戻すための「対応表」ファイルが自動で保存されます（保存場所はマスク完了メッセージに表示されます）。この対応表は復元に必要なので消さないでください。
>
> ⚠️ クリップボードのマスクで作られる対応表は **毎回同じファイルに上書き** されます。復元がまだ済んでいないうちに次のクリップボードマスクを行うと、前の内容は元に戻せなくなります。続けて使う場合は、先に復元を済ませるか、対応表を別名でコピーして取っておいてください。

### 復元する（AI の回答を受け取った後）

1. AI が返してきた回答（`【人名_1】` などの記号が含まれた文章）をコピーします。
2. アプリ画面上部で **「復元」** に切り替えます。
3. **「クリップボードを復元してコピー」** ボタンを押します。
4. 対応表ファイルを選ぶ画面が出るので、先ほど保存された対応表を選びます。
5. クリップボードの中身が、元の名前や番号に戻ります。貼り付けて確認してください。

## ③ ファイルやフォルダをまとめてマスクする

Excel・Word・PowerPoint やテキストファイルは、**アプリの点線の枠にドラッグ＆ドロップ** するだけでマスクできます（枠をクリックしてファイルを選んでもOK）。フォルダを丸ごと入れれば、中のファイルを一括処理します。

### 確認画面（プレビュー）で目視チェック

ファイルをドロップしたとき、「確認なしで即変換」にチェックを入れていない場合は、マスク実行の前に **確認画面** が開きます。ここが最も大切なステップです。

> ⚠️ **フォルダを丸ごとドロップした場合は、この確認画面は開きません**（中のファイルをまとめて自動で処理します）。目視で確認したいファイルは、フォルダごとではなく **ファイル単位でドロップ** してください。

<p align="center">
  <img src="docs/images/preview-dialog.png" alt="検出結果の確認画面" width="720">
</p>

- **左側**：見つかった個人情報が色付きでハイライトされます。
- **右側**：見つかった項目の一覧です。チェックを外すと、その項目はマスクされません（隠したくないものを除外できます）。
- **隠し忘れを見つけたら**：左側の文章で対象の文字を **マウスで選択（ドラッグ）** するだけで、その部分がマスク対象に加わります。
- **隠さなくてよいものを見つけたら**：左側の色が付いた部分を **クリック** すると、その項目のマスクが外れます（色が消えます）。もう一度クリックすれば元に戻ります。
- **種類を変えたいときは**：右側の一覧で項目を **右クリック** すると、「人名」「組織」などの種類を選び直せます。
- **同じ言葉をまとめて扱いたいときは**：上部の **「同じ語をまとめて扱う（全出現をまとめてマスク）」** にチェックを入れます。同じ言葉が何度も出てくる文章で、一覧が 1 行にまとまり、1 か所を選ぶだけで**同じ言葉すべて**がマスク対象になります。
- 内容を確認したら、右下の **「この内容でマスク実行」** を押します。

処理が終わると、元のファイルと同じ場所に **マスク済みのファイル** が新しく作られます（元のファイルはそのまま残ります）。

## ④ AI の回答を元に戻す（復元）

ファイルを復元する場合は、次のようにします。

1. アプリ画面上部で **「復元」** に切り替えます。
2. マスク済みのファイル（`〇〇_masked.docx` など）を枠にドラッグ＆ドロップします。
3. 同じ場所にある「対応表」を自動で探して、元に戻したファイルを作ります。
   （対応表が見つからない場合は、選ぶ画面が出ます）

> 💡 復元は「完全に一致する記号」だけを元に戻します。AI が記号を書き換えてしまった場合（例：`【人名_1】` → `[人名1]`）、その部分は元に戻せず、そのまま残ります。この場合は「未知トークン◯件」と知らせが出ます。

---

## 2 つのマスク方式

画面上部で、隠し方を 2 種類から選べます。

| 方式                     | 表示例       | 元に戻せる？ | こんなときに                                                    |
| ------------------------ | ------------ | ------------ | --------------------------------------------------------------- |
| **可逆（トークン）**     | `【人名_1】` | ✅ 戻せる     | AI に相談して、回答を元の名前で受け取りたいとき（通常はこちら） |
| **不可逆（塗りつぶし）** | `●●●●`       | ❌ 戻せない   | 完全に消したいとき。公開資料の作成など                          |

迷ったら **「可逆（トークン）」** を選んでください。

## 設定とカスタム辞書

メイン画面の **「設定」** ボタン（または「ツール」→「設定...」）から、検出のしかたを調整できます。設定画面は 2 つのタブに分かれています。

**検出カテゴリ**タブ：人名・住所・電話番号などのうち、自動で検出する種類のオン／オフを切り替えられます。

<p align="center">
  <img src="docs/images/settings-dialog.png" alt="設定画面（検出カテゴリ）" width="500">
</p>

**カスタム辞書**タブ：自動では見つけられない社名・製品名・プロジェクト名などを登録しておくと、必ずマスク対象になります。「行を追加」で語句を入れ、種別を選ぶだけです。メイン画面の **「辞書を編集」** ボタンを押すと、このタブが開いた状態で表示されます。

<p align="center">
  <img src="docs/images/settings-dictionary.png" alt="設定画面（カスタム辞書）" width="500">
</p>

- `CSVインポート` / `CSVエクスポート` で、辞書を一括で読み込み・保存できます。

> 💡 カスタム辞書に登録した語句は、上の「検出カテゴリ」のオン／オフに関わらず、**必ず**マスクされます。

## 処理レポートの見方

マスクや復元が終わると、結果のレポートが表示されます。

<p align="center">
  <img src="docs/images/report-dialog.png" alt="処理レポート画面" width="560">
</p>

- ファイルごとに「どの種類の情報を何件隠したか」が件数で表示されます。
- **プライバシー保護のため、隠した実際の値（名前や番号そのもの）はレポートには一切表示されません。**
- 「検出0件」と出た場合は、個人情報が本当になかったか、**検出漏れの可能性**があります。念のため内容をご確認ください。

## 対応しているファイルの種類

| 種類       | 拡張子                                                           |
| ---------- | ---------------------------------------------------------------- |
| Excel      | `.xlsx`                                                          |
| Word       | `.docx`                                                          |
| PowerPoint | `.pptx`                                                          |
| テキスト系 | `.txt` `.csv` `.json` `.md` `.log` `.xml` `.html` `.yaml` `.yml` |

Excel の数式や書式、Word・PowerPoint のレイアウトなどはそのままで、**文字の部分だけ**を置き換えます。

## 作られるファイルについて（重要）

マスクすると、次のファイルが作られます（元のファイルは消えません）。

| ファイル                    | 内容                                           |
| --------------------------- | ---------------------------------------------- |
| `〇〇_masked.docx` など     | マスク済みのファイル。これを AI などに渡します |
| `〇〇_masked.docx.pmap.csv` | **対応表**。どの記号が元は何だったかの一覧です |
| `_folder.pmap.csv`          | フォルダを一括処理したときの、共通の対応表     |
| `〇〇_restored.docx` など   | 復元したファイル                               |

> 🔑 **対応表（`.pmap.csv`）は絶対に消さないでください。** これがないと、マスクした情報を元に戻せなくなります。マスク済みファイルと同じ場所に一緒に保管しておくことをおすすめします。

## 困ったときは（よくある質問）

**Q. 起動時に「Windows によって PC が保護されました」と出ます**
→ 「詳細情報」→「実行」で起動できます（[インストール手順](#-ダウンロードとインストール)を参照）。

**Q. 最初の起動や最初のマスクに時間がかかります**
→ 日本語を解析する仕組みを読み込むため、初回は少し時間がかかることがあります。2 回目以降は速くなります。処理中は進捗バーが表示されます。

**Q. 隠したい情報がマスクされませんでした**
→ 自動検出は完璧ではありません。①確認画面で、その文字をマウスで選択して手動で追加する、②「辞書を編集」からカスタム辞書に登録しておく、のいずれかで対応できます。同じ言葉が何度も出てくる場合は、確認画面の「同じ語をまとめて扱う」にチェックを入れてから選択すると、まとめてマスクできます。

**Q. 復元したら「未知トークン◯件」と出ました**
→ AI が記号を書き換えてしまった可能性があります。書き換えられた記号は自動では戻せないため、その箇所は手作業で直してください。

**Q. 対応表をなくしてしまいました**
→ 申し訳ありませんが、対応表がないと元に戻すことはできません。マスク済みファイルと一緒に大切に保管してください。

**Q. マスクした情報はどこかに送信されますか？**
→ いいえ。すべてお使いのパソコンの中だけで処理され、インターネットには一切送信しません。

## 安全性・プライバシーについて

- **完全ローカル動作**：このアプリはインターネット通信を行いません。あなたのデータが外部に送られることはありません。
- **元のファイルは変更しません**：マスク・復元とも、常に新しいファイルを作ります。
- **対応表は「暗号化されていない」CSV です**：これは、対応表を人が確認・編集できるようにするためです。このアプリの目的は「クラウドの AI に個人情報を渡さないこと」であり、パソコン内のファイルの盗難対策ではありません。対応表ファイルの保管場所にはご注意ください。

## 開発者向け情報

ソースコードから実行・ビルドする場合の情報です（一般の利用者は読む必要はありません）。

- 言語：Python 3.11 以上 / GUI は PySide6
- 日本語の固有表現抽出に GiNZA（`ja_ginza`）、Office ファイル処理に openpyxl・python-docx・python-pptx を使用

依存関係は [uv](https://docs.astral.sh/uv/) で管理しています（`uv.lock` が正）。

```bash
# セットアップ（uv.lock どおりに .venv を作成／更新）
uv sync --extra dev

# テスト実行
uv run pytest tests/ -v

# アプリを起動
uv run python -m privacyprotection.gui.app

# 配布用の実行ファイル（.exe）をビルド
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
# → dist/PrivacyProtection.zip が作られます
```

設計書は [`docs/`](docs/README.md)、設計方針や実装上の注意点は [`AGENTS.md`](AGENTS.md) を参照してください。
